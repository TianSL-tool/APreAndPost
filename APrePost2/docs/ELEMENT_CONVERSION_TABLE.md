# 单元互转能力表

本表对应 `aprepost2.services.mesh_operations.convert_element_types_by_material()`。
控制文件格式与“按材料修改单元类型”一致：

```text
材料数量
材料号1
...
转换对数量
旧类型 新类型
...
```

转换只作用于指定材料号且当前 `t_id` 命中旧类型的单元。转换时保留
`e_id, c_id, m_id, d_id, f_id`，只重建拓扑 Payload 和目标 `t_id`。

## 已实现转换

| 来源 | 目标 | 支持的 t_id | 转换方式 | 反向限制 |
|---|---|---|---|---|
| `QuadSolid2D` | `PolygonSolid2D` | `1/2/222 -> 44/47/470` | 4 个角点直接作为多边形节点 | 多边形必须恰好 4 节点才能转回 |
| `PolygonSolid2D` | `QuadSolid2D` | `44/47/470 -> 1/2/222` | 4 节点多边形转四节点常规二维单元 | 节点数不是 4 时拒绝 |
| `QuadraticTriangle2D` | `EdgeStructured2D` | `11/121/122 -> 443/444/644` | 3 个角点 + 3 个边中点转边结构化二维单元 | 转回时必须是 3 条二阶边 |
| `QuadraticQuad2D` | `EdgeStructured2D` | `102/103/104 -> 443/444/644` | 4 个角点 + 4 个边中点转边结构化二维单元 | 转回时必须是 4 条二阶边 |
| `EdgeStructured2D` | `QuadraticTriangle2D` | `443/444/644 -> 11/121/122` | 3 条二阶边转常规二阶三角形 | 边数或边阶次不匹配时拒绝 |
| `EdgeStructured2D` | `QuadraticQuad2D` | `443/444/644 -> 102/103/104` | 4 条二阶边转常规二阶四边形 | 边数或边阶次不匹配时拒绝 |
| `Hexahedron` | `Polyhedron` | `5/6/23/61/500 -> 53/57/59/80/800` | 用 `Hexahedron.faces()` 写成面结构化多面体 | 转回时要求 6 个四边形面能唯一识别为六面体 |
| `Polyhedron` | `Hexahedron` | `53/57/59/80/800 -> 5/6/23/61/500` | 根据一对相对四边形面还原六面体节点顺序 | 不是 8 节点、6 四边形面或拓扑不匹配时拒绝 |
| `HigherOrderHexahedron` | `HigherOrder` | `16/510/511 -> 508/805/807` | 20 节点六面体转 6 个二阶四边形面 | 转回时要求面结构与标准 20 节点六面体完全匹配 |
| `HigherOrderWedge` | `HigherOrder` | `18/170/171 -> 508/805/807` | 15 节点三棱柱 A 转 3 个四边形面 + 2 个三角形面 | 转回时要求面结构与该排序完全匹配 |
| `HigherOrderWedgeAlt` | `HigherOrder` | `20/190/191 -> 508/805/807` | 15 节点三棱柱 B 转 3 个四边形面 + 2 个三角形面 | 转回时要求面结构与该排序完全匹配 |
| `HigherOrder` | 常规三维高阶 | `508/805/807 -> 16/18/20/170/171/190/191/510/511` | 仅当可唯一还原为目标常规高阶节点排序时转换 | 任意高阶、跨阶或面顺序不匹配时拒绝 |
| `HigherOrder` | 自动常规三维高阶 | `508/805/807 -> 0` | 目标类型写 `0` 表示自动识别常规高阶；按表格顺序选择第一项 | 无对应项时输出任意高阶面结构说明 |

| `EdgeStructured2D` | 自动常规二维二阶 | `443/444/644 -> 0` | 按边数（3→三角形/4→四边形）和响应类型自动匹配目标 t_id | 边数不是 3 或 4、非统一二阶边或响应类型无对应时拒绝 |

自动目标 `0` 不是真实单元类型，只是控制文件中的转换指令：

- `508 -> 0`：依次尝试 `16, 18, 20`；
- `805 -> 0`：依次尝试 `510, 170, 190`；
- `807 -> 0`：依次尝试 `511, 171, 191`；
- `443/444/644 -> 0`：按边数选目标类，按源响应类型（单相/直接求解/交叉迭代）匹配目标 t_id：
  - 3 边 → `QuadraticTriangle2D`（`443→11`，`444→121`，`644→122`）
  - 4 边 → `QuadraticQuad2D`（`443→103`，`444→102/103`，`644→104`）

例如某个 `508` 的面结构能匹配 20 节点六面体和其他候选时，程序按表格第一项输出
`16`。如果都不匹配，错误信息会列出该任意高阶的 `n_faces`、每面边数、逐边阶次和
每面节点数，并说明“无对应的常规单元”。

## 同结构改响应类型

同一具体类内部的响应类型转换仍由 `replace_element_type()` 安全处理，例如：

| 具体类 | 单相 | 饱和多孔介质直接求解 | 饱和多孔介质交叉迭代 |
|---|---|---|---|
| `QuadSolid2D` | `1` | `2` | `222` |
| `QuadraticTriangle2D` | `11` | `121` | `122` |
| `QuadraticQuad2D` | - | `102, 103` | `104` |
| `Hexahedron` | `6, 61` | `5` | `500` |
| `Polyhedron` | `53, 57, 59` | `80` | `800` |
| `HigherOrder` | `508` | `805` | `807` |

`23` 当前没有响应类型标识，只能作为已注册拓扑类型参与显式旧类型到新类型转换。

## 当前不自动推断的情况

- 任意节点数多边形自动转三角形、四边形以外的常规单元；
- 任意多面体自动转非六面体常规三维单元；
- 任意高阶 `HigherOrder` 在面顺序、边阶次或节点排序不完全匹配时转回常规高阶；
- 会改变节点数量、创建新节点或删除节点的转换。

这些情况需要专门算法和工程规则确认后再加入，避免破坏节点连接、面法向或高斯点约定。
