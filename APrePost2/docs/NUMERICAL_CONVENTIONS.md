# 数值与工程约定

## 网格

- 节点坐标不自动换算单位。
- 节点、单元、材料和填筑编号均按整数处理。
- 普通单元保持输入节点顺序；57/59 等多面体显式保存每个面的节点顺序。
- 单元形心沿用原程序约定：对去除重复坐标后的节点取算术平均，而非体积形心。

## 三维切割

- 切割面由三个不共线点定义，法向量由右手定则计算。
- 切割使用带容差的半空间多边形裁剪，当前要求被切单元为凸多面体。
- 凸性检查只用某一面的外部节点判断是否位于该面外侧；同一面自身节点不参与外侧判定，
  以允许工程六面体常见的轻微翘曲四边形面。
- 交点按 8 位小数坐标全局合并；原节点编号不变，新节点从原最大编号加一开始。
- 输出单元按原遍历顺序重新连续编号；实体切割结果为 57 型多面体，界面切割结果为 60 型。
- 57 型多面体的每个面要求节点顺序满足右手定则，面法向指向单元外侧；写出前会检查该约定。
- 默认自动执行边界处理，把相邻单元棱边上的新交点插入其面拓扑，避免悬挂节点；
  控制文件末尾明确写入边界模式 0 时可关闭，1 和 2 均表示开启。
- 切割生成交点时记录其所属原始边；边界协调按边索引插入交点，不再对所有新节点做全局线段搜索。
- 构造 57 型多面体前，只沿同一切割面在单元面上形成的两个点拆分面片；切割面贯穿角点时，
  面片沿真实切割线拆分，不使用任意对角线。
- 切割完成后会向运行日志输出控制读取、网格读取、筛选切割、边界协调、重编号校验和写出阶段的耗时。

## HDF5 结果

- `stress_i`、`strain_i`、位移、速度和加速度列保留 HDF5 原始符号。
- 派生应力和应变采用岩土工程常用的压缩为正约定，即
  \(\boldsymbol{\sigma}=-\boldsymbol{\sigma}_{raw}\)、
  \(\boldsymbol{\varepsilon}=-\boldsymbol{\varepsilon}_{raw}\)。
- 三维应力分量顺序为
  \((\sigma_x,\sigma_y,\sigma_z,\tau_{xy},\tau_{yz},\tau_{zx})\)。
- 二维应力分量顺序为
  \((\sigma_x,\sigma_y,\sigma_z,\tau_{xy})\)。
- HDF5 剪应变按 engineering shear strain（工程剪应变）解释，组装应变张量时除以 2。
- \(p=\mathrm{tr}(\boldsymbol{\sigma})/3\)，
  \(q=\sqrt{3J_2}\)；主值使用对称张量的 `eigvalsh` 计算并按降序排列。
- `initial stress = 0` 或 `initial strain = 0` 表示各步减去第一步结果。
- 指定 `base node` 时，其他节点位移按相同 frame 减去基准节点位移。

## 反演插值

- 监测时间与计算时间统一转换为时间戳后进行分段线性插值。
- 目标时间超出有效时程范围时输出 0，不做外推。
- 测值、计算值、CAD 坐标偏移和标注缩放分别保留独立系数。

这些约定必须结合求解器输出说明和工程项目采用的正负号、单位体系进行复核。
